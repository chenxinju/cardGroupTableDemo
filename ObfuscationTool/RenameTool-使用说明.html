RenameTool — iOS 类名混淆

使用说明

完成度 功能 打开 类名规则 字段说明 任务预设 中间词库 操作流程 注意

完成度

已可用：单任务混淆与回滚。
未做：多阶段流水线连跑。多阶段请分步执行，或使用 CLI JSON。

功能介绍

macOS 图形工具，批量重命名 iOS/macOS 工程中的类名，并同步更新引用与 pbxproj。按所选规则生成「旧名 → 新名」映射，写入源码，并将 mapping JSON 保存到指定目录，供回滚或复用。

仅换前缀

只改类名前缀。适合统一品牌前缀。

全量随机

前缀 + 随机中间词 + 类型后缀。适合强混淆。

回滚

按 Mapping JSON 还原类名。多步混淆须按相反顺序回滚。

打开方式

  • App / DMG：安装后启动 RenameTool；窗口内点「使用说明」可打开本文档。
  • 源码：用 Xcode 打开 ObfuscationTool/RenameTool.xcodeproj，scheme 选 RenameTool，按 ⌘R。

类名规则

仅换前缀

ABCFooView → XYZFooView（中间与后缀不变）

全量随机

前缀 + 随机中间词 + 类型后缀

例：ABC + NovaPulse + ViewModel → ABCNovaPulseViewModel

字段与选项

字段说明 / 示例
project_path 源码根目录（通常为 …/Sources）。 例：…/MyApp/Sources
maps_dir 混淆时写出 mapping JSON 的目录。 例：…/ObfuscationTool/maps
Mapping JSON 回滚 / 复用时读入的具体 json（非 maps_dir）。 例：…/maps/rename_20261019.json
target_folder 仅混淆该子目录；空 = 整个 project_path。回滚不用。 例：Features/Home
pbxproj 可空；空则自动推断 …/AppName.xcodeproj/project.pbxproj。勿误填 Sources.xcodeproj。
任务预设 切换常见模式（见下节）。
旧前缀 / 新前缀 仅换前缀时填写；预设不写死具体值。 例：旧 ABC,DEF → 新 XYZ
回滚模式 勾选后进入回滚；无关项置灰。主要填 project_path + Mapping JSON。
复用旧 mapping 按已有 Mapping JSON 再应用同一映射，不重新随机。
中间词库 / 词包 仅全量模式可用；仅换前缀 / 回滚时置灰。
Python / 脚本路径 执行混淆的 Python3 或脚本入口；一般保持默认。跑不通时确认本机有可用 python3。
速记
混淆：project_path = Sources，maps_dir = json 输出目录，target_folder 按需，pbxproj 可空。
回滚：同一 project_path + 对应 Mapping JSON；无需 target_folder。

任务预设

  • 自定义 — 自行勾选与填写。
  • ① 仅换前缀 — 自行填旧/新前缀（各项目不同，不写死）。
  • ② 全量随机中间词 — 自行填前后缀（常填相同，表示保留前缀、只随机中间）。
  • ③ 同 ②，并展开词库面板 — 结果与 ② 相同，仅打开词库 UI。

中间词库

仅全量模式可用。内置词包为不同英文词风的可选词表（词包A / 词包B / 词包C / 词包D），与具体工程无关；也可选自定义自行编辑。切换词包只影响随机中间词来源，不会绑定或写入任何项目路径。

操作流程

混淆

  1. Xcode 打开 RenameTool.xcodeproj，scheme RenameTool，⌘R。
  2. project_path 指向目标工程 …/Sources。
  3. maps_dir 选独立目录存放 mapping（勿与源码混放）。
  4. 需限定范围时填 target_folder；否则留空。pbxproj 不确定则留空。
  5. 预设选 ①（换前缀）或 ②/③（全量）；填好前缀或前后缀 + 词包。
  6. 执行。查看窗口下方日志；确认 maps_dir 中新生成的 Mapping JSON（回滚需用）。
  7. 回 Xcode 编译目标工程。若报错：关闭工程后重开；勿手动批量重新添加文件。

回滚

  1. 勾选回滚模式。
  2. project_path 指向需恢复的 Sources。
  3. Mapping JSON 选对应阶段写出的文件（非 maps_dir）。
  4. 多步混淆时：后生成的 mapping 先回，再回更早的。
  5. 完成后若 Xcode 仍报错：关工程再开。仍红则查窗口下方日志。

注意

  • 前缀因项目而异，预设不填具体前缀。
  • maps_dir 是写出目录；回滚 / 复用依赖 Mapping JSON 指向的具体文件。target_folder 回滚时不用。
  • 多步回滚必须逆序，否则映射可能对不上。
  • 日志与 Mapping 结果在窗口下方，可拉宽查看。
  • 多阶段连跑未实现：请分步手动，或使用 CLI JSON。
